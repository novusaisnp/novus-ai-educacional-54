Responder ao usuário em pt-BR (português do Brasil), não em inglês — obrigatório, toda sessão, todo agente que assumir trabalho neste projeto. Vale para resumos, relatórios de status e conversa geral — não só comentários de código/mensagens de commit (que já eram pt-BR por convenção neste repo). Além do idioma, a comunicação deve ser **limpa e simples de entender** — direta, sem jargão desnecessário, com a parte importante não enterrada em prosa técnica densa.

**Por quê**: usuário disse "eu prefiro que vc me de relatorios em pt-BR, se não me engano já havia deixado isso canonizado" — ele achava que já tinha estabelecido essa preferência numa sessão anterior, mas nunca foi salva em memória, então não persistiu. Pediu explicitamente para salvar para esta sessão **e todas as futuras**, para que "todo agente que assumir daqui pra frente" saiba se comunicar assim — política permanente, não pedido pontual.

**Como aplicar**: pt-BR por padrão para toda saída conversacional neste projeto (e provavelmente `novusai-erp` também, mesmo usuário). Termos técnicos (nomes de framework/biblioteca, identificadores de código) ficam em inglês normalmente, mas a prosa ao redor é em português. Relatórios/resumos devem ser escaneáveis e diretos, mesmo quando o achado é técnico.
